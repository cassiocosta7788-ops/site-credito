# ◎ Recuperador de Sites

Plataforma web com interface para análise de sites, registros de pagamentos, assistente NEURA AI e relatórios.

## Funcionalidades

- Painel principal com indicadores.
- Análise de conteúdo público de sites, quando permitido pelo navegador.
- Registro local de pagamentos fictícios.
- Área de referências de pagamento.
- Interface preparada para integração com inteligência artificial.
- Relatórios para impressão e salvamento em PDF.
- Layout responsivo para computador e celular.

## Arquivos

- `index.html` — estrutura da aplicação.
- `style.css` — estilos e layout.
- `script.js` — funcionalidades JavaScript.

## Como executar

1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador moderno.
3. Para publicar, configure o GitHub Pages nas configurações do repositório.

## Estado do projeto

Esta é a versão inicial da aplicação.

Os pagamentos ainda são registros locais, a NEURA AI precisa de um backend e a leitura de sites externos depende das permissões de acesso e das políticas CORS.

Não insira senhas, chaves de API ou dados financeiros confidenciais na interface.

## Tecnologias

- HTML5
- CSS3
- JavaScript
